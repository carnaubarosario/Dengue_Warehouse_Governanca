# Instalar tudo de uma vez:
#   pip install -r requirements.txt
#
# Pre-requisitos que NAO sao instalados via pip:
#   - PostgreSQL 14+ (o banco em si, nao a lib Python)
#   - Java + JAVA_HOME configurado (exigido pelo PySpark)
#   - Google Chrome instalado (o Selenium controla o Chrome via
#     webdriver-manager, mas o navegador em si precisa existir)
#   - Hadoop local no Windows (winutils.exe) se for rodar PySpark
#     no Windows -- ver HADOOP_HOME no topo do script
